# OpenALD v1.0

**OpenALD** is an open, rechargeable pocket FM radio: an ATmega328PB + RDA5807M (RRD-102 module) board that runs from one
18650 cell, charges and programs over a centred USB-C port, and lives in a 3D-printed 43 × 92 × 33.4 mm case. The repo also
holds an **Adafruit Feather RP2040 variant** built from off-the-shelf boards, and a **6-slot USB-C PD charging dock** that
fits both radios. Everything is KiCad 9 + OpenSCAD, generated by Python scripts.

> **Status: designed, CAD- and datasheet-checked, NOT built and NOT hardware-validated.** ERC/DRC, the JLC placement
> check and the 3D case-fit checks pass, but no board has been built, powered or programmed, and there is no firmware yet.
> Treat the first build of each part as a prototype (see the bring-up checklist in [HANDOFF.md](HANDOFF.md#8-hardware-bring-up-test-checklist)).

**Picking this up later (person or AI)? Start with [HANDOFF.md](HANDOFF.md)**: full design history, decisions, hard
constraints, open TODOs, test checklist and exact regeneration commands.

## How to order (JLCPCB)
**Board settings for every board:** 2 layers, **1.6 mm** FR-4, **1 oz** copper, any colour, HASL lead-free (or ENIG),
**PCB Assembly: Economic, top side**. Upload the gerber zip from the subproject's `fab/`, then the `*-BOM-jlcpcb.csv` and
`*-CPL-jlcpcb.csv`. Use the centroid `.csv` or `.pos` only if a site asks for those formats.

* **Check every part's rotation in JLC's placement preview before paying.** The CPLs already contain per-part EasyEDA
  origin/rotation corrections (`JLC_CORR`, verified by `jlc_cpl_fit.py --check`), so the preview should be right; JLC
  engineers sometimes re-rotate by hand.
* Single-board radio: U4 (RRD-102 module), BT1 (18650 holder) and J3 (ISP pads, do not fit) are hand-solder/DNP.
  SW1 (SK-12E12-G5) is THT: choose Standard PCBA to have JLC fit it, or deselect it and hand-solder (5 joints).
  If the ATmega328PB (C132230) is low/out of stock, use **ATmega328P-AU (C14877)**, a drop-in (pick the 328P variant in MiniCore).
* **Minimal assembly option** (you have hot air/hotplate): upload the same gerbers with
  `radio_single_board/fab/minimal/openald-BOM-jlcpcb-minimal.csv` + `openald-CPL-jlcpcb-minimal.csv`. JLC places only
  J1 (USB-C), U1 (TP4056), U3 (ATmega328PB) and U7 (CH340K); buy the rest from LCSC with
  `fab/minimal/openald-LCSC-order-handsolder.csv` (5 boards + labelled spares). Order a separate **frameless** stencil
  (~$3) if you want one for hand paste.
* Dock: the six vertical USB-C plugs J2–J7 (HX TYPE C-M 16P V-SMT, **LCSC C55200592, low stock**) are hand-soldered; buy 7.
* Other vendors (PCBWay/NextPCB) have filled BOM templates, but **the CPL/placement files contain JLC-specific
  corrections**; generate a clean placement file before using another assembler (see HANDOFF §6).
* Cost figures in the docs are **estimates from published price tables (2026-11-10/11)**, not quotes.

## How to regenerate / check
Tested with: **KiCad 9.0.2** (`kicad-cli` + `pcbnew` Python module), **OpenSCAD 2021.01**, **Python 3.13**,
Freerouting (2026-10 build, Java 21+; run with OpenJDK 25) for re-routing only. Python packages: see
[`requirements.txt`](requirements.txt) (`pcbnew` comes with KiCad, not pip).

```bash
pip install -r requirements.txt
tools/fetch_kicad3d.sh && export KICAD9_3DMODEL_DIR=$PWD/tools/kicad3d   # stock KiCad STEP models for the fit checks
tools/check_all.sh            # ERC + DRC + JLC CPL check for all three boards (non-destructive, ~10 s)
tools/check_all.sh --case     # + rebuild cases and run the 3D fit checks (slow; rewrites STLs/previews)
```
Per subproject (details and expected results in [HANDOFF.md §7](HANDOFF.md#7-regeneration-and-checks)):
* `radio_single_board/scripts/run_all_pcb.sh` (full schematic → board → **re-route** → DRC; needs Freerouting),
  `python3 scripts/make_fab.py` / `--minimal`, `python3 scripts/make_vendor_boms.py`, `scripts/build_case.sh`.
* `charging_dock/scripts/run_all_pcb.sh`, `python3 scripts/make_fab.py`, `scripts/build_case.sh`.
* `radio_adafruit_feather_rp2040/make_all.sh` (everything) or `case/build_case.sh` (case only).
* `OPENALD_OFFLINE=1` makes `make_fab.py` reuse the saved `fab/lcsc_lookup.json` prices instead of querying JLC's parts API.
* `FREEROUTING=/path/freerouting.jar` and `JAVA=/path/java` override the router location (default `tools/freerouting.jar`, not in git).
* `EASYEDA_CACHE` overrides the EasyEDA footprint cache used by `jlc_cpl_fit.py` (default: the committed `tools/easyeda/`).
